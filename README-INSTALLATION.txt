HYROX COACH — installation Android

IMPORTANT : une PWA doit être servie par HTTPS pour que le bouton « Ajouter à l'écran d'accueil » et le mode hors-ligne fonctionnent correctement.

Option simple :
1. Décompresse ce ZIP.
2. Héberge le contenu du dossier sur un hébergeur statique HTTPS (par exemple GitHub Pages, Netlify ou Vercel).
3. Ouvre l'adresse HTTPS dans Chrome sur Android.
4. Menu ⋮ → « Ajouter à l'écran d'accueil » / « Installer l'application ».

Les données (validations, charges et personnalisations) sont stockées localement dans le navigateur.

Le plan est prévu du 05/10/2026 au 12/12/2026, avec course le 12/12.
